# Mis XV años de Naiara Elizabeth | Vista previa

Primera propuesta de invitación web interactiva para Kreativo Invitaciones.

## Contenido

- Portada interactiva con sobre y botón para abrir.
- Presentación, fecha, padres y padrinos de velación.
- Lugares de ceremonia y recepción.
- Código de vestimenta, lluvia de sobres y agradecimiento al padrino de vestido.
- Cuenta de días hasta el 26 de diciembre de 2026 (sin inventar una hora del evento).
- Formulario que prepara un mensaje de confirmación y lo abre en WhatsApp al número proporcionado por la clienta.
- Adaptación para celular y computadora.

## Para publicarla gratis en GitHub Pages

1. Crear un repositorio nuevo. **No sustituir el repositorio de Karol Fernanda.**
2. Subir `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. En **Settings > Pages**, elegir **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.
4. Entrar a la URL de GitHub Pages cuando esté publicada.

También puedes abrir `index.html` directamente en tu computadora para hacer una prueba local.

### Nota importante sobre confirmaciones

El formulario **no registra confirmaciones en una base de datos** ni envía mensajes por sí solo. Abre WhatsApp con un mensaje preparado para que el invitado lo envíe. Esto permite probar la confirmación sin configurar Supabase.

### Estilo y tipografías

Marfil, oliva y champaña. No se emplea azul porque ese color está reservado para la quinceañera. Fuentes: **Cormorant Garamond**, **Great Vibes** y **DM Sans** (Google Fonts, con alternativas de sistema).
