PARA SUBIR A GITHUB:
1. Abre tu repositorio Mis-15-a-os-Naiara-Elizabeth.
2. Ve a Code > Add file > Upload files.
3. Sube index.html, style.css, script.js, foto-naiara.jpg,
   Papel_Chic_mp3.mp3 y sello-lacre-naiara.webp.
4. Confirma con Commit changes.
5. Abre GitHub Pages en tu celular y recarga la página.

Los botones de ubicación siguen enlazados a las rutas que se configuraron
anteriormente; el usuario debe comprobar que llegan al acceso correcto.
La confirmación abre WhatsApp con el mensaje listo; el invitado debe enviarlo.
