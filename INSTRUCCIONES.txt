PASOS PARA ACTUALIZAR GITHUB
1. Descomprime el ZIP.
2. Abre el repositorio de la invitación de Naiara en GitHub.
3. En Add file > Upload files, sube LOS CINCO ARCHIVOS listados arriba
   en el nivel principal del repositorio. Reemplaza los archivos que
   ya existan. No subas el ZIP como archivo de la página.
4. Presiona Commit changes.
5. Abre o actualiza la dirección de GitHub Pages de ese repositorio.
